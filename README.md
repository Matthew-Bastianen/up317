## Research Question

How does Chicago maintain affordability where other large cities have suffered?

## Data Sources

U.S. Census Bureau. (2026).
American Community Survey 5-Year Estimates, (2019-2024). http://api.census.gov/data/2024/acs/acs5​


## Methods

1. Exploratory spatial data analysis (mapping)
2. Spatial weights matrix (Queen contiguity)
3. Global Moran's I test
4. Local Indicators of Spatial Association (LISA)
5. Sensitivity analysis (p-values, weight specifications)
